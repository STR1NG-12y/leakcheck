leakcheck 使用说明
==================

一、这是什么
  判断一段要发出去的内容里，有没有本地敏感文件的原样内容。
  有两种用法：图形界面（推荐）、命令行。

二、启动

  【图形界面】
    双击 leakcheck.exe          → 直接打开窗口
    或 双击 启动界面.bat        → 源码方式启动
    或 命令行: python -m leakcheck.gui

  【命令行 / 控制台菜单】
    leakcheck.exe menu            → 中文菜单
    leakcheck.exe demo            → 内置演示
    leakcheck.exe build --dir "D:\资料" -o leakcheck.idx
    leakcheck.exe match --index leakcheck.idx --file prompt.txt
    leakcheck.exe scan  --dir "D:\资料" --file prompt.txt
    leakcheck.exe screen --dir "D:\资料" --file prompt.txt

三、图形界面怎么用
  左栏六页，点按钮切换：

    ① 建立索引    选敏感资料目录 → 点「开始建索引」
    ② 路径判定    选文件或目录 → 看哪些会被保护
    ③ 两阶扫描    索引 + 待检测（文件/目录/jsonl）→ 逐字 + 骨架
    ④ 语义筛选    向量模型找相似块（线索，不自动阻断）
    ⑤ 关键词      直接改文字 → 点「保存」
    ⑥ 设置        看程序目录、索引状态，可删索引

  快捷键：F5 运行当前页，Ctrl+O 选目录，Esc 退出。

四、结果怎么读
  [A] 逐字命中      可以确定是复制，建议阻断
  [B] 骨架/语义命中  改写过，建议告警 + 人工确认
  [C] 语义召回       只是"像"，需要人工判断
  放行              没发现重合

五、索引只需要建一次（重要）
  ① 建立索引 → 生成 leakcheck.idx（内含 逐字 + 骨架 两层）
  之后 ③ 两阶扫描 直接读这个文件，不用再扫目录。
  ③ 页面「索引文件」填 leakcheck.idx 即可；留空则现场重建（慢，仅调试用）。

六、第一次用
  1. 打开界面 → ① 建立索引 → 选你的敏感资料目录
  2. 等它扫描完（生成 leakcheck.idx，在程序旁边）
  3. 到 ③ 或 ④ 选一个待检测文件 → 点开始
  4. 看底部结果表

六、注意
  - leakcheck.idx 里是敏感原文的副本，不要外发
  - 关键词改完要重建索引才生效
  - 支持 txt/md/csv/代码；docx/pdf/xlsx 需要额外装库（会提示）
  - 扫描件 OCR 未内置
  - 分发时整个文件夹一起发（_internal 不能少）

七、从源码运行（开发用）
  python -m leakcheck.gui                               打开界面
  python -m leakcheck demo                              内置演示
  python -m unittest discover -s leakcheck/tests -t .   跑测试

八、示例（第一次用建议先跑这个）
  示例\敏感资料\   三份假的敏感文件（合同片段、代码、薪酬表）
  示例\待检测\     三条待检测内容
    1-逐字复制.txt  → 应报 [A] 逐字命中
    2-改写过.txt    → 应报 [B] 骨架命中
    3-无关内容.txt  → 应放行

  操作：双击 leakcheck.exe → ④ 两阶扫描
        敏感资料目录：示例\敏感资料
        待检测文件：  示例\待检测\1-逐字复制.txt

九、语义筛选（已内置模型）
  models\ 里已经放好 bge-small-zh（ONNX，92 MB），打开程序就能用。
  界面 ⑤ 语义筛选 → 选敏感资料目录 + 待检测文件 → 开始筛选。

  结果是一串相似度分数（0~1）：
    0.55 以上才会显示；越高越像
    0.9 以上 ≈ 原样
    0.65~0.8 ≈ 改写过
    0.55~0.65 ≈ 只是同一话题

  ⚠ 这只是"线索"，不是证据，不会自动阻断。
    要判定是否泄露，看 ④ 两阶扫描的 A / B 级结果。

  换模型：见 models\放模型到这里.txt
